# Backend Engineer at Northstar Parcel Labs

Northstar Parcel Labs is a fictional parcel-tracking software company hiring a Backend Engineer. Build and maintain Python APIs for parcel status, use PostgreSQL for event history, add automated tests, and collaborate with support engineers to diagnose delayed or duplicated updates. We value clear communication and practical tradeoffs. Experience with FastAPI, SQL, pytest, and background jobs is helpful.

## Company context

The fictional team receives duplicate and out-of-order delivery webhooks. It values idempotency, monitoring, and clear incident handoffs.
